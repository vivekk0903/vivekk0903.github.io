Clinical Document Parsing System

Organization: AGS Health

Timeline: 2023

Description: Created a system to parse diverse medical document formats, enabling automated data extraction for AI model training.

Tools Used: Google Cloud Vision, AWS Textract, Azure AI Vision, Python, GCP BigQuery, Azure Blob Storage

Modality: Text, images (scanned PDFs, handwritten notes)

Techniques/Architectures: Optical Character Recognition (OCR), generative AI for text normalization, regex-based parsing

Key Contributions:

  • Fine-tuned OCR models, achieving 90% text extraction accuracy on complex medical PDFs.
  • Built scalable data ingestion pipelines, processing 10TB+ datasets.
  • Applied generative AI to standardize extracted text, improving training data quality by 25%.

Impact: Cut manual preprocessing by 50%, saving 200+ hours monthly, with applications in data processing across sectors.
