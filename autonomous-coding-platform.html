Autonomous Medical Coding Platform

Organization: AGS Health

Timeline: 2023 - Present

Description: Strategized and developed an AI platform for automated coding of ICD10CM, CPT, and E&M codes, streamlining healthcare billing processes.

Tools Used: AWS SageMaker, Azure Machine Learning, Python, PyTorch, MLFlow, Prefect, MySQL

Modality: Text (clinical notes, medical reports)

Techniques/Architectures: Transformer-based NLP (BERT, RoBERTa), multi-label classification, generative AI for data augmentation

Key Contributions:

  • Designed NLP models to classify codes, achieving 75%+ accuracy across 1M+ documents annually.
  • Built MLOps pipelines for automated retraining, cutting deployment time by 40%.
  • Ensured HIPAA compliance for 10TB+ datasets, supporting scalable analytics.

Impact: Reduced coding time by 45%, saved $2M annually for clients, and enhanced operational efficiency.
