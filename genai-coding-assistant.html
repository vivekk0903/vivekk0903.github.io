GenAI-Powered Medical Coding Assistant

Organization: AGS Health

Timeline: 2024 - Present

Description: Led development of a conversational AI agent using large language models to assist medical coders in real-time, enhancing accuracy and efficiency for SaaS platforms.

Tools Used: LangChain, Hugging Face Transformers, OpenAI GPT-4, AWS Bedrock, Triton Inference Server, Python, MySQL

Modality: Text (clinical notes, EHR data)

Techniques/Architectures: LLMs (GPT-4), Retrieval-Augmented Generation (RAG), prompt engineering, multi-turn dialogue systems

Key Contributions:

  • Built a context-aware assistant with LangChain, enabling multi-turn conversations and reducing coding time by 20%.
  • Fine-tuned GPT-4 on 500K+ medical records, improving domain-specific accuracy by 15%.
  • Deployed on AWS Bedrock with Triton, achieving sub-second response times for 10,000+ daily queries.

Impact: Increased coder productivity by 25%, reduced errors by 20%, and saved $1M annually, demonstrating scalability for healthcare and SaaS applications.
